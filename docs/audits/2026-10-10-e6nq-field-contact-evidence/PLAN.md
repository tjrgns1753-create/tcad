# E6N-Q: 실제 노드 필드의 2단자 기록 완전성

시작 HEAD: af63e0973e008c74a6b5ab43f30b4b5392b30b48.

## 목적과 범위

화면의 실제 노드 필드를 저장할 때 전압·전류의 접점 집합이 다르거나
한쪽 접점 기록이 없으면 완전한 2단자 측정 증거로 인정하지 않는다.
이는 물리 구성방정식 변경이 아니라 이미 계산한 결과의 증거 경계다.
일반 BiasPoint에는 다단자 데이터가 있으므로 공통 validator를 강화하지
않고, 현재 2단자 단일 bias 필드 저장 함수에만 계약을 명시한다.

## 사전 판정 기준

- 수정 전: 유한하고 converged인 합성 단일 접점 / 불일치 접점 결과가
  JSON으로 저장되는 것을 재현한다. 합성 자료는 물리 결과가 아니다.
- 수정 후: voltages와 currents가 동일한 두 개의 비어 있지 않은 문자열
  접점 이름을 가져야 한다. sweep_contact도 그 집합에 있어야 한다.
- 접점 누락·추가·서로 다른 이름·잘못된 이름이면 저장 이전에 거부하며,
  기존 대상 파일의 모든 바이트를 보존하고 임시 파일도 남기지 않는다.
- 실제 측정의 접점 이름을 a/b처럼 고정하지 않는다. 음수 전류·0 전류,
  비영 전위 기준은 허용한다. KCL 임계값이나 새로운 전위 보정은 도입하지 않는다.
- 기존 단일 bias / region / 단위 / 비유한값 / 출처 검사를 유지한다.

## 검증 및 자원

로컬은 순수 Python 테스트만 실행하며 엔진·Tk import를 trap한다.
원격 GitHub-hosted Windows에서 기존 E6NO 실제 export 검사와 관련 국소
대조군을 재사용한다. 기존 동일 uniform ACTIVE Si, +1mV, 73 노드 조건은
변경하지 않는다. 실제 저장 결과의 접점 집합·모든 노드 배열·단위·출처를
이전 고정 증거와 독립 비교한다. 부모 원격 실행 350초, 개별 30~120초,
산출물 8MB 상한을 유지한다. 전체 회귀 및 PN 확대 검증은 하지 않는다.
