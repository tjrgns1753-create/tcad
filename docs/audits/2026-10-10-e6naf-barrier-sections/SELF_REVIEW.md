# 자체 검토 보완 (물리 입력 및 판정 기준 불변)

첫 원격 38054731192는 8개 검사 모두 성공했다. 뒤이어 자체 검토에서
중복 삼각형이 모든 경계를 상쇄할 때 빈 material로 잘못 읽힐 수 있음을 발견.
동일 인덱스 중복/음수 인덱스 반례를 추가하고 CCW 경계 winding을 검사해
겹친 material과 열린 경계를 명시적으로 거부한다. 순서 섞기와 y축 교환,
기존 실제 18 column 비교는 엔진 없이 다시 통과했다.

새 원격 실행은 같은 PLAN/물리 입력/8개 검사로 보완된 코드를 확인하는 용도다.
첫 성공 결과를 최종 보완 코드의 검증으로 소급 사용하지 않는다.
