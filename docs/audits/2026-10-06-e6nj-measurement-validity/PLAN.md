# E6N-J 측정 입력·결과 유효성 계약

물리 모델 변경이 아니라 측정 경계의 거짓 정상 표시를 막는다.
NaN/±Inf 전압은 엔진 준비 전에 거부한다. 정상 반환했더라도
미수렴·빈 전류·누락 접점·비유한 전압/전류를 성공으로 표시하지 않는다.
DC 재시도 시작 시 이전 CSV 결과를 제거해 실패 결과와 혼동하지 않는다.
정상 유한값과 부호는 그대로 보존하며 임계값·반올림·숫자 대체는 없다.

허용 변경: characterization/interface.py 순수 결과 검사, GUI 측정/DC
입출력 경계, 신규 테스트와 이 감사 폴더 및 원격 실행 설정.
방정식, 엔진 내부, 도핑/mesh/PN/산화 gate는 변경하지 않는다.

수정 전: 이전 DC 결과를 넣은 상태에서 pins 미해결 재시도가 이전 결과를
남기는 반례를 재현한다. 수정 후: 순수 AST 추출 메서드 및 합성 결과 검사,
실제 Tk invalid-input 트랩, 기존 실제 uniform DD 정상·unsupported
대조군을 원격에서 실행한다. 합성 결과 검사는 물리 정확성 증거가 아니다.
실제 uniform 대조군 역시 PN/MOSFET 일반 검증을 의미하지 않는다.
전체 회귀 및 gate 해제 없음. 실제 엔진 계산은 원격에서만 수행한다.

후속 검토 보완: 기존 DC 정상 mock의 전압/수렴 필드가 누락되어 있어
실제 BiasPoint 형식으로 fixture만 보완한다. gate 전류는 만들어 넣지 않는다.
정상 DD가 반환한 뒤 NaN 전류/미수렴 플래그를 의도적으로 주입해
GUI 성공 표시가 차단되는지 검사한다. 이것은 엔진 결함 관측이 아니다.
